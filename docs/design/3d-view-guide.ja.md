# 3D ビュー 操作ガイド

- ステータス: 実験的機能（Experimental）。設定でオンにするまで非表示です
- 対象バージョン: P0〜P5 実装時点（コミット `6ae99b45` 相当）
- 関連ドキュメント: [3d-view.ja.md](./3d-view.ja.md)（設計書）

このガイドは、OpenMarch デスクトップアプリに実装済みの3Dビューを実際にどう操作するかをまとめたものです。設計書（3d-view.ja.md）が「なぜこう作ったか」を説明する技術文書なのに対し、こちらは「今の実装で何ができて、どう触るか」だけを扱います。

---

## 1. 有効化

3Dビューは既定でオフです。

1. アプリ設定（起動画面の「Settings」）→ **General** を開く
2. **「3D view (experimental)」** のスイッチをオンにする

オンにすると、ツールバーの **View** タブに 2D/3D/分割表示の切り替えが現れます。

---

## 2. 表示モードの切り替え

ツールバー「View」タブの左端に3つのボタンがあります。

| モード | アイコン | 内容                                                                           |
| ------ | -------- | ------------------------------------------------------------------------------ |
| 2D     | 四角     | 従来通りの2Dキャンバスのみ                                                     |
| 3D     | 立方体   | 3Dビューのみ（2Dキャンバスは裏で非表示のまま動き続け、再生・ページ更新は継続） |
| Split  | 分割線   | 2Dと3Dを左右に50:50で並べて表示                                                |

**キーボードショートカット:** `Shift + 3` で 2D ⇔ 3D をトグル（分割表示には切り替わりません）。

---

## 3. カメラ操作

### 自由視点（マウス操作）

3Dビュー内でマウスをドラッグすると、その場でプリセットが自動的に「Free view（自由視点）」に切り替わります。

- **左ドラッグ:** 視点を回転（オービット）
- **右ドラッグ:** 平行移動（パン）
- **ホイール:** ズーム

地面より下には潜れず、フィールドサイズに応じたズーム距離の上限・下限があります。

### カメラプリセット

3Dビュー右上のドロップダウンから選択、またはキーボードショートカットで切り替えます。プリセット間は約0.6秒でなめらかに移動します。

| プリセット                       | ショートカット | 内容                                                                                |
| -------------------------------- | -------------- | ----------------------------------------------------------------------------------- |
| Press box（プレスボックス）      | `Alt + 1`      | スタンド中央上空から見下ろす標準視点                                                |
| Front row（前列）                | `Alt + 2`      | スタンド前列からの低い視点                                                          |
| End zone（エンドゾーン）         | `Alt + 3`      | 横方向からの視点                                                                    |
| Top down（真上）                 | `Alt + 4`      | 上空から見下ろす視点                                                                |
| Field level（フィールドレベル）  | `Alt + 5`      | マーチャー目線に近い低い視点                                                        |
| Follow selected marcher（追従）  | なし           | 選択中の先頭マーチャーを追いかける（マーチャーを選択していないと選べません）        |
| Camera keyframes（キーフレーム） | なし           | 後述のキーフレームで作ったカメラワークを再生（キーフレームが1つもないと選べません） |

---

## 4. 表示オプション

### ツールバー「View」タブ（3Dが有効な間のみ表示）

目のアイコンで表示/非表示をトグルします。

- **3D labels** — ドリルナンバーのラベル表示
- **3D stands** — 観客席・トラックの表示
- **3D shadows** — 影の表示
- **3D equipment** — フラッグ・ライフル・楽器の表示

### アプリ設定（Settings → General、3Dビューが有効な場合のみ表示）

- **3D marcher size** — マーチャーの表示倍率（50%/75%/100%/150%/200%）
- **3D marcher model** — 「Walking figure（歩行モデル）」か「Simple shape（単純な形状）」
- **Glide between pages in 3D** — 停止中にページを切り替えたときの位置遷移をなめらかにするかどうか

---

## 5. マーチャーの選択・移動(3Dビュー上での編集)

再生が止まっている間のみ操作できます(再生中はクリックがカメラ操作に回されます)。

- **クリック:** マーチャーを選択(2D側の選択と共有されます)
- **Shift / Ctrl / Cmd + クリック:** 選択に追加・除外
- **空白部分をクリック:** 選択解除
- **ドラッグ:** 選択中のマーチャーを地面上で移動。2Dキャンバスと同じデータベース更新経路を通るため、`Ctrl/Cmd + Z` で元に戻せます
- **Shift を押しながらドラッグ:** スナップを一時的に無効化(2Dと同様)
- **Esc:** ドラッグ中のキャンセル
- 形状(シェイプ)に属してロックされているマーチャーは、2D同様ドラッグできません

> ⚠️ **既知の問題:** マーチャーをドラッグ中に `e` / `q` キーでページを切り替えると、離した時点の新しいページに古いページの座標が書き込まれてしまう不具合が確認されています(コードレビュー済み・未修正)。**ドラッグ中はページ切り替えキーを押さないでください。**

## 6. カメラキーフレーム

3Dビュー左上の動画カメラアイコンをクリックするとパネルが開きます。

1. カメラを好きな位置に動かす(プリセットでも自由視点でも可)
2. 再生ヘッドを目的の時刻・ページに合わせる
3. **「Add current view」** をクリックすると、現在のカメラ位置と現在の再生時刻でキーフレームが1件追加される
4. 一覧の各行で以下が操作可能:
   - 時刻(秒)を直接編集
   - **目のアイコン(Show this view)** — そのキーフレームの視点に一時的にジャンプ
   - **ゴミ箱アイコン(Delete keyframe)** — 削除
5. カメラプリセットを **「Camera keyframes」** に切り替える(プリセットメニュー、または一覧上部の **「Play through」**)と、再生中および3D動画書き出し時にキーフレーム間をカメラが自動で移動します

キーフレームはショーファイル(`.dots`)に保存されます。localStorage ではないため、ファイルを開き直しても、共有しても保持されます。

> ⚠️ **既知の問題(2件、未修正):**
>
> 1. 既存のキーフレームと同じ時刻に別のキーフレームの時刻を編集すると、後勝ちで元のキーフレームが**無言で削除**されます(この保存経路はアンドゥ非対応のため復元できません)。他のキーフレームと時刻が被らないよう注意してください。
> 2. 一覧の各行の時刻入力欄を編集すると、その行がDOM上で作り直されるため、稀に編集中のフォーカスが不安定になることがあります。

## 7. フラッグ・ライフルの演出（トス・スピン・スイープ）

フラッグ（Flag / Color Guard）とライフル（Rifle）に、具体的な技を割り当てられます。技を指定しないときは、これまでどおり構えたままです。3Dビュー右上のカメラメニューの下にある旗アイコンをクリックするとパネルが開きます。

### 技の種類

| 技       | 動き                                                                                               | 「回数」の意味       |
| -------- | -------------------------------------------------------------------------------------------------- | -------------------- |
| トス     | 手を離れてまっすぐ上がり、回転しながら落ちてきて同じ手に戻る。高さは滞空時間（技の長さ）から決まる | 空中での回転数       |
| スピン   | 手元を軸に、観客に向いた面（マーチャーの正面）で回す。始めと終わりはなめらかに構えへつながる       | 技の間の回転数       |
| スイープ | 手元を支点に、左右へ大きく（約75°）振る。フラッグ向き                                              | 左右に振る往復の回数 |

- 回転はマーチャーの正面から見た向きで、**時計回り / 反時計回り** を選べます。
- 回数は整数にすると、技の終わりに元の構えへ戻ります（0.5 などにすると、終わりの瞬間に構えへ切り替わります）。

### 追加のしかた

1. 演出を付けたい **ページを選択**します（カウントのあるページのみ。最初のページには付けられません）
2. 旗アイコンでパネルを開き、次を指定して **「Add move」**（演出を追加）をクリックします
   - **対象**: セクション全員（Flag・Rifle など）、または選択中のマーチャー
   - **技**・**向き**
   - **開始**: ページの先頭からのカウント（0 = ページの最初のカウント）
   - **長さ**: 技にかかるカウント数（最大64。ページの終わりを越えて次のページにまたがってもかまいません）
   - **回転数 / 振り回数**
3. 一覧の各行で、目のアイコン（プレビュー）・鉛筆（編集）・ゴミ箱（削除）が使えます

- **プレビュー**: 停止中でも、その技の途中の姿をスライダーで確認できます（そのページの隊形で表示されます）。再生を始めると解除されます。
- 同じマーチャーに重なる技があるときは、そのマーチャーだけに付けた技がセクション全体の技より優先され、それ以外は後から追加したものが優先されます。
- 時刻はカウントで持つため、テンポを変えても技はカウントに追従します。ページを削除すると、そのページの技は無効になります。
- 技が反映されるのは **「3D equipment」がオン** のときです。3D動画の書き出しにも自動で反映されます。
- 技はショーファイル（`.dots`）に保存されます。カメラキーフレームと同じく、元に戻す（Undo）の対象外です。

> ⚠️ **見た目についての注意:** 腕の動きや旗の布のはためきは表現していません。手を離れる瞬間・受ける瞬間も、棒と布が剛体として動くだけです。体ごとの演技は次の第8章（演技モーション）で付けられます。

## 8. 演技モーション（モーションキャプチャの取り込み）

ガードなどの実際の演技を、関節のある人型でなめらかに再現します。動きそのものは外部ツールで作り、ファイルとして読み込みます。3Dビュー右上の人のアイコン（旗アイコンの左）でパネルが開きます。

### 動きの作り方（外部ツール）

| 方法                            | ツールの例                                          | 書き出す形式    |
| ------------------------------- | --------------------------------------------------- | --------------- |
| Webカメラ・動画からのモーキャプ | XR Animator、MocapForAll、Rokoko Video、Mocapy など | BVH             |
| 3Dソフトで手付け・修正          | Blender                                             | BVH / glTF・GLB |
| 既存モーションの利用            | Mixamo                                              | FBX             |

- 演技者は **カメラ（＝観客席）に正面を向いて** 撮ると、そのまま正面向きで取り込めます。取り込み時に、上方向・正面の向き・身長（フィギュアの大きさに合わせる）は自動でそろえます。
- 撮影中に歩き回った分（ゆっくりした移動）は取り除き、マーチャーはドリルの位置で演技します。ランジのような素早い体重移動は残ります。
- 動きの長さは 180 秒まで、1 ショーに 64 個までです。

### 振り付け動画から作る（アプリ内）

外部ツールを使わずに、ガードの振り付け動画から直接モーションを作れます。パネルの **「動画から作成」** をクリックします。

1. **「動画を選ぶ」** で動画ファイルを開きます（MP4 / H.264 がおすすめ）。初回だけ姿勢推定モデル（約 9 MB）をダウンロードするため、インターネット接続が必要です。2 回目以降はオフラインでも使えます。
2. 動きの始まりで一時停止し、**追いかける演技者をクリック** します。見つかった人に棒人間が重なり、選んだ人が黄色になります。その位置が開始位置になります（クリックしない場合は、一番大きく映っている人を追いかけます）。
3. 動きの終わりで **「ここまで」** を押します。開始位置だけ変えたいときは **「ここから」** を押します（演技者は選び直してください）。
4. 名前となめらかさを確かめて **「モーションを抽出」** を押すと、1/30 秒ごとに演技者の姿勢を読み取ります。進み具合が表示され、途中でキャンセルできます。終わるとモーション一覧に追加され、キューのフォームに入った状態になります。

- 姿勢の読み取りはすべてこのパソコンの中で行い、**動画はどこにもアップロードされません**。
- 向いている動画: 演技者を **正面から、全身が映るように** 撮ったもの。客席からの通し動画でも、演技者が大きめに映っていれば使えます。
- 他の人と重なって見えなくなったフレームは前後から補います。演技者が全体の 60% 未満のフレームでしか見つからないときは、範囲の選び直しを求めます。
- 動画からの推定は腰を基準にした姿勢だけなので、**ジャンプの高さは再現されません**（膝立ち・床の振りは地面に着いたまま再現されます）。旗の向きは手の位置からの推定です。
- 抽出には時間がかかります（目安: 動画 1 分で数分、GPU が使えない環境ではさらに長くなります）。

### 使い方

1. **なめらかさ（ブレ補正）** を選んで **「読み込む」** をクリックし、ファイルを選びます。Webカメラのモーキャプは細かく震えやすいので、既定の「中」がおすすめです（「強」はさらになめらかですが、素早い動きが少し鈍ります）。
2. 演技させたい **ページを選択**し、次を指定して **「キューを追加」** をクリックします
   - **モーション**・**対象**（セクション全員、または選択中のマーチャー）
   - **開始**（ページの先頭からのカウント）・**長さ**（カウント数、最大 512）
   - 長さに合わせてモーションを **伸び縮み** させるので、テンポを変えてもカウントに合います。「元の速さにする（N カウント）」を押すと、撮影したときの速さになる長さが入ります。
   - **ポールの下側の手**: フラッグの下端（ライフルはお尻側）を持つ手
   - **左右を反転**: 鏡像で撮れてしまったとき、または左右逆の振付にしたいとき
3. 一覧の目のアイコンで、停止中でもスライダーで演技の途中を確認できます（装備の演出のプレビューとは同時に使えません）。

### 表示のされ方

- キューの間だけ、そのマーチャーは **関節のある人型**（胴体・頭・腕・手・脚・足）で描かれます。胴体と腕はマーチャーの色です。キューの最初と最後の約 0.35 秒で、立った姿勢とのあいだをなめらかにつなぎます。
- **フラッグ・ライフルは演技者の手に追従** します。両手が近いときは下側の手からもう一方の手を通る向き、片手のときは前腕に直交して、できるだけ立てた向きになります。第7章のトス・スピン・スイープを同じ時間に付けると、手に持った状態から技を重ねます。ドラムは腰について動きます。
- 同じマーチャーに重なるキューは、マーチャー個別のキューがセクションのキューより優先され、それ以外は後から追加したものが優先されます。
- 再生中と 3D 動画の書き出しに反映されます（書き出しのオプションでの切り替えはなく、キューがあれば常に反映されます）。
- モーションとキューはショーファイル（`.dots`）に保存されます。元に戻す（Undo）の対象外です。モーションを削除すると、それを使うキューも一緒に削除されます。

> ⚠️ **注意:** 指や手首のひねりは取り込まないため、フラッグの向きは手の位置からの推定です。布のはためきもありません。カメラ 1 台のモーキャプは奥行き方向の動きが不正確になりがちなので、気になるときは Blender で修正してから読み込んでください。

## 9. VR表示

3Dビューの「View in VR」ボタンから、WebXR対応のVRヘッドセットを接続していれば没入表示に入れます。ヘッドセットが認識されない場合は「Could not start VR. Check that the headset is connected.」と表示されます。

## 10. 3D動画の書き出し

「Export Coordinates」モーダルの動画書き出しで、3Dレンダラーを選択できます。

- **Camera** — Press box などの固定プリセット、Follow(マーチャー追従。追従対象を選択)、Camera keyframes から選択
- **Walking figures** — 歩行モデルで書き出すか
- **Stands / Shadows / Drill number labels / Flags, rifles & instruments** — それぞれ表示のオン/オフ。フラッグ・ライフルの演出（第7章）は「Flags, rifles & instruments」がオンのとき、自動で動画に反映されます。演技モーション（第8章）は常に反映されます
- 情報オーバーレイ(セット番号・カウントなど)は2D側で位置調整したものがそのまま3D動画にも合成されます

> ⚠️ **既知の問題:** このセッションで一度も3Dビューを開かずに動画書き出しモーダルを開くと、ショーに保存済みのカメラキーフレームがまだ読み込まれておらず、「Camera keyframes」を選んでいても**無言でPress boxにフォールバック**することがあります(未修正)。**保存したキーフレームで書き出したい場合は、先に一度3Dビューを開いてから書き出しモーダルを開いてください。**

---

## 11. WebGLが使えない場合

ハードウェアアクセラレーションが無効などの理由でWebGLが使えない環境では、3D表示ボタンが自動的に無効化され、「The 3D view is unavailable because WebGL could not start. Hardware acceleration may be turned off.」と表示されます。

---

## 12. 既知の問題まとめ

このガイド作成時点のコードレビューで見つかった、修正待ちの不具合です。

| 重大度 | 内容                                                                               | 回避策                                   |
| ------ | ---------------------------------------------------------------------------------- | ---------------------------------------- |
| HIGH   | マーチャーのドラッグ中にページを切り替えると別ページの座標が壊れる                 | ドラッグ中はページ切り替えキーを押さない |
| HIGH   | 3Dビュー未訪問のまま動画書き出しを開くと保存済みキーフレームが無視される           | 書き出し前に一度3Dビューを開く           |
| MEDIUM | キーフレームの時刻を既存の時刻と重複させると片方が無言で消える                     | 時刻が重複しないようにする               |
| MEDIUM | 選択中マーチャーが変わるたびに無関係な再描画が走る(表示上の実害なし)               | 特になし                                 |
| MEDIUM | キーフレームパネルの各行の aria-label が同一文言でスクリーンリーダーで区別できない | 特になし                                 |
